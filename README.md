# 🌌 EVRENİN EN YAVAŞ FİBONACCİ MAKİNESİ

## Resmi Duyuru

Sayın Dünya Vatandaşları, Uzaylılar ve Dijital Varlıklar,

Bu depo, insanlık tarihinin (ve muhtemelen evrenin) **en yavaş**, **en bürokratik**, **en resmi** ve **en gereksiz** Fibonacci sayı dizisi hesaplayıcısını barındırmaktadır.

### Neden Bu Kadar Yavaş?

Çünkü her hesaplama adımında:
1. Resmi mühür basılır
2. 3 saniye boyunca derin düşünceye dalınır
3. Bürokratik onay süreci simüle edilir
4. "Bu sayı gerçekten gerekli mi?" sorusu sorulur
5. Cevap "hayır" olsa bile devam edilir

### Teknik Özellikler

- Python 3 ile yazılmıştır (çünkü başka dil bu kadar yavaş olamazdı)
- Her adımda `time.sleep(3)` ile zaman kaybeder
- Konsola resmi damga basar
- Fibonacci sayısını hesaplar ama asla acele etmez
- Sonuçları "Resmi Fibonacci Beyannamesi" formatında sunar

### Nasıl Çalıştırılır?

```bash
python fibonacci_makinesi.py
```

Sonra sabırla bekleyin. Belki bir çay koyun. Belki iki. Belki de bu arada hayatınızı yeniden gözden geçirin.

### Uyarı

Bu programı çalıştırmak:
- Zamanınızı çalar
- Sabırınızı test eder
- Fibonacci'nin kendisini utandırır
- Bürokrasiye olan inancınızı sarsar
